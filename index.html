    나의 상담 길잡이 사용법

    다운로드한 HTML 파일을 브라우저로 열면 됩니다. 상담 내용과 검색은 인터넷 없이 작동하며, 외부 자료 링크를 열 때만 인터넷이 필요합니다.

    현장에서 이렇게 사용하세요

    1. 현재 단계 또는 검색으로 상황을 찾습니다.
    2. ‘보호자에게 / 어르신에게’를 선택해 멘트를 읽습니다.
    3. 상대에게 화면을 보여줄 때는 ‘보여주기’를 누릅니다. 상담자 메모가 숨겨지고 글씨가 커집니다.
    4. 별표로 자주 쓰는 상황을 모아두세요. 체크는 이번 실행 중에만 유지되며 파일을 다시 열면 초기화됩니다.

    파일과 설정

    즐겨찾기와 글씨 설정만 현재 브라우저에 저장합니다. 이름·연락처·건강정보를 입력하거나 외부로 전송하는 기능은 없습니다. 파일 위치나 브라우저를 바꾸면 즐겨찾기가 이어지지 않을 수 있습니다.

    휴대폰에서는 파일을 다운로드한 뒤 HTML 실행이 가능한 브라우저에서 열어주세요. 파일 미리보기 앱에서는 버튼이 작동하지 않을 수 있습니다. 앱 설치나 홈 화면 등록은 필요하지 않습니다.
